# Backend сервис Estate Operations System

Этот каталог содержит серверную часть приложения Estate Operations System. Проект реализован на TypeScript с фокусом на стабильность, читаемость и поддержку современных практик REST API.

Доступ к backend осуществляется по ссылке:
```bash
https://backend-pl4x.onrender.com
```

## Описание

Backend предоставляет API для управления пользователями, заявками и парковочными местами. Он работает с PostgreSQL, обеспечивает авторизацию по JWT, отправку уведомлений по Email и интеграцию с Telegram.

Основные возможности:
- регистрация и аутентификация пользователей
- управление заявками и комментариями
- история изменения статусов заявок
- управление парковочным пространством
- отправка email-уведомлений
- Telegram-бот для уведомлений и управления событиями
- Swagger документация для API

## Технологии

- Node.js
- TypeScript
- Express
- PostgreSQL
- JWT (jsonwebtoken)
- express-session
- nodemailer
- node-telegram-bot-api
- Swagger (swagger-jsdoc + swagger-ui-express)
- Jest для тестирования
- ESLint + Prettier для контроля качества кода
- ts-node / nodemon для запуска в режиме разработки

## Структура проекта

- `src/app.ts` — основной Express-приложение
- `src/server.ts` — точка запуска сервера
- `src/routes/` — маршруты API
- `src/controllers/` — обработчики запросов
- `src/models/` — модели данных и взаимодействие с БД
- `src/config/` — конфигурация базы данных, инициализация и служебные скрипты
- `src/middleware/` — middleware для аутентификации и безопасности
- `src/utils/` — утилиты для сообщений, цвета и токенов
- `src/types/` — декларации типов для TypeScript
- `src/__tests__/` — модульные тесты

## Установка и запуск

```bash
cd backend
npm install
```

### Запуск в разработке

```bash
npm run dev
```

### Сборка проекта

```bash
npm run build
```

### Запуск собранного приложения

```bash
npm run start
```

## Работа с базой данных

Для инициализации базы данных и заполнения начальными данными:

```bash
npm run db:init
```

## Тестирование и качество кода

### Запуск тестов

```bash
npm run test
```
